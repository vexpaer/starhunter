# StarHunter

StarHunter is an independent, two-person telescope design project. **We have not raised outside funding.**

Live site: https://vexpaer.github.io/starhunter/

## Website

This repository contains a single static landing page (`index.html`) with inline CSS and JavaScript; no build step is required.

The telescope models, technical specifications, app screens, test data and related editorial content are **illustrative early-stage concepts**, not verified production claims. The interest form is a non-submitting UI preview: it does not collect email addresses, process payments or create orders. The site does not represent actual availability or customer reviews.

The team consists of **two people**. Names and biographies are intentionally not published here.
